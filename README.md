# ダンスイベント 投票システム

祭りのダンスイベント用の、その場で投票できる仕組みです。
**サーバー不要・無料**で、投票結果は Google スプレッドシートに溜まります。

```
   来場者のスマホ                GitHub Pages            Google
  ┌──────────┐   QR   ┌──────────────┐        ┌──────────────────┐
  │ 投票ページ │ ─────> │ index.html   │ ─────> │ Apps Script      │
  │（1組を選択）│        │（静的サイト）  │        │  ↓               │
  └──────────┘        └──────────────┘        │ スプレッドシート   │
                                               └──────────────────┘
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `config.js` | **設定ファイル。基本ここだけ編集します**（イベント名・ダンサー一覧・合言葉・接続先URL） |
| `index.html` | 投票ページ。QRコードの読み取り先 |
| `results.html` | 結果発表ページ。自動更新するランキング。スクリーン投影用 |
| `qr.html` | QRコードを作って印刷するページ |
| `gas/Code.gs` | Google Apps Script に貼り付けるサーバー側のコード |
| `assets/` | CSS と JavaScript |

## セットアップ手順（所要 20〜30分）

### STEP 1. スプレッドシートと Apps Script を用意する

1. [Googleスプレッドシート](https://sheets.new) を新規作成し、名前を付ける（例：`祭りダンス投票2026`）
2. メニューの **拡張機能 → Apps Script** を開く
3. 出てきたエディタの中身を全部消し、`gas/Code.gs` の中身を**すべて**貼り付ける
4. ファイル上部の「設定」を書き換える（合言葉・受付時間。使わないなら空のままでOK）
5. 保存し、関数の一覧から `setup` を選んで**実行**
   - 初回は権限の確認が出ます → 「詳細」→「（プロジェクト名）に移動」→「許可」

### STEP 2. ウェブアプリとしてデプロイする

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車アイコン → **ウェブアプリ** を選択
3. 設定を次のようにする（**ここが最重要**）
   - 次のユーザーとして実行： **自分**
   - アクセスできるユーザー： **全員**
4. デプロイを押すと `https://script.google.com/macros/s/XXXXXXXX/exec` というURLが出る
5. このURLをコピーしておく

> ⚠️ あとで `Code.gs` を修正したときは、**デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ** を必ず行ってください。これを忘れると変更が反映されません。

### STEP 3. config.js を書き換える

`config.js` を開いて、次の4か所を編集します。

```js
GAS_URL: "STEP2でコピーしたURL",
EVENT_TITLE: "○○祭り ダンスコンテスト",
VENUE_CODE: "",          // 合言葉を使うならここに（Code.gs と同じ文字列にする）
DANCERS: [
  { id: "01", name: "チーム1", note: "" },   // ← 10チーム分が入っています
  { id: "02", name: "チーム2", note: "" },
  // …
]
```

- 初期状態で **チーム1〜チーム10 の10組**が入っています。そのままでも使えます
- 実際のチーム名が決まったら `name` だけ書き換えてください（例: `name: "さくら連"`）
- `id` は**あとから変更しない**でください（集計のキーになります）
- 組数を変えるときは行ごと追加／削除します。何組でもOKです

### STEP 4. GitHub Pages に公開する

1. GitHub で新しいリポジトリを作る（例：`dance-vote`／Public）
2. このフォルダの中身をアップロードする

   **方法A：Web画面から**
   「Add file → Upload files」で `index.html` `results.html` `qr.html` `config.js` と
   `assets` フォルダをドラッグ&ドロップ → Commit

   **方法B：ターミナルから**
   ```bash
   cd /Applications/MAMP/htdocs/vote
   git init
   git add .
   git commit -m "投票システム"
   git branch -M main
   git remote add origin https://github.com/ユーザー名/dance-vote.git
   git push -u origin main
   ```

3. リポジトリの **Settings → Pages** を開く
4. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 1〜2分待つと `https://ユーザー名.github.io/dance-vote/` で公開されます

> `gas/` と `README.md` も一緒に上がりますが、閲覧されて困る情報は入っていません。
> 気になる場合は `gas/` をアップロードしなければOKです。

### STEP 5. QRコードを作る

1. `https://ユーザー名.github.io/dance-vote/qr.html` を開く
2. URL欄に投票ページのURL（`https://ユーザー名.github.io/dance-vote/`）が入っていることを確認
3. サイズを調整して「印刷 / PDF保存」
4. 会場のスクリーンに映す場合は、このページをそのまま投影してもOK

## 当日の流れ

| タイミング | やること |
|---|---|
| 開演前 | `results.html` を別タブで開いておく（「結果を伏せる」を押しておくと安心） |
| 投票開始 | QRコードをスクリーンに投影／掲示。合言葉を使う場合は口頭で伝える |
| 投票中（5分） | `results.html` で票数の伸びを確認。放っておいても6秒ごとに自動更新されます |
| 締め切り | スクリーンからQRを外す。（`Code.gs` の `CLOSE_AT` を設定していれば自動で締切） |
| 発表 | `results.html` の「結果を表示する」を押して投影 |

スプレッドシート側では、メニュー **「ダンス投票」→「集計を更新」** で
`集計` シートに順位・得票数・得票率が書き出されます。

## 「1人1回だけ」について

完全な本人確認をしない以上、100%は防げません。この仕組みでは**現実的に十分な**
次の4段階で重ねて防いでいます。

1. **端末IDによる判定（主軸）**
   初回アクセス時に端末ごとのランダムIDを発行し、localStorage と Cookie の
   **両方**に保存。スプレッドシート側で同じIDの投票があれば拒否します。
   片方を消しても、もう片方から復元されます。
2. **投票済み画面**
   一度投票した端末で開き直すと、投票内容とともに「投票済みです」と表示されます。
3. **会場の合言葉**（`VENUE_CODE`／任意）
   URLだけを外部にSNS等で拡散されても、合言葉を知らない人は投票できません。
   **これが会場外からの組織票に一番効きます。**
4. **受付時間の制限**（`OPEN_AT` / `CLOSE_AT`／任意）
   5分間だけ受け付けるようにすれば、そもそも不正を仕込む時間がありません。

**突破される余地**（承知のうえで運用してください）
- シークレットモードで開き直す／別のブラウザを使う
- 家族や友人のスマホを借りる

より厳密にしたい場合は、受付で**1枚ずつ違う番号を印刷した紙**を配り、その番号を
投票時に入力させる方式が有効です（必要なら追加実装できます）。

## よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| 「送信できませんでした」と出る | デプロイの**アクセスできるユーザー**が「全員」になっていない。STEP2をやり直す |
| コードを直したのに反映されない | Apps Script を**新バージョン**で再デプロイしていない |
| 「設定が未完了です」と出る | `config.js` の `GAS_URL` が未設定 |
| 結果ページが空のまま | まだ1票も入っていない／`GAS_URL` が違う |
| 合言葉が通らない | `config.js` と `Code.gs` の `VENUE_CODE` が食い違っている |

## 事前テストのすすめ

本番前に必ず、**自分のスマホ（Wi-Fiを切ってモバイル回線）**で一度投票してみてください。
スプレッドシートに行が増え、`results.html` に反映されればOKです。
テストの票は、スプレッドシートのメニュー
**「ダンス投票」→「投票データを全消去」** で消せます。

## ローカルで確認する場合

MAMP を起動して `http://localhost:8888/vote/` を開けば動作確認できます
（`GAS_URL` さえ設定されていれば、ローカルからでも投票は記録されます）。
